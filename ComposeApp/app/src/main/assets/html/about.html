不挂科课表

版本 - · 选学校 · 登教务 · 一键导入课表

主要功能

教务网页导入选学校登录教务，一键导入课程、周次、地点与教师
宿舍开门登录一次后本机蓝牙开门；支持长按图标「快速开锁」，可选指纹/面容验证
洗衣房门店可搜索 / 按附近选择，看洗衣机、烘干机哪台空着，一键去小程序开洗
多课表与周视图多套课表并存随时切换，左右滑动换周、今日高亮
今日页正在上课 / 下一节课 / 今日时间轴
桌面小组件课程 2×2 / 3×2 / 4×2（今明双栏）＋ 洗衣房 2×1 空闲速览
上课提醒课前 5/10/15/20 分钟本地通知，准点触发
系统日历同步课程直接写入系统日历，可一键清空
课表对比与调课截图识别占用找共同空闲；长按拖拽跨天跨节次调课，也可按日期整日调课（落点覆盖）
个性化贴纸风亮 / 暗双主题、自定义纸面背景与作息

v1.5

  • 校园页新增「洗衣房」：门店可搜索 / 按附近选择，查看洗衣机、烘干机实时状态与剩余时间，空闲的排前面，剩余时间本地倒计时
  • 设备一键跳转官方小程序开洗；查询无需登录、不上传任何数据，下单与支付仍在官方小程序完成
  • 新增 2×1「洗衣房」桌面小组件：速览上次浏览楼栋的空闲洗衣机 / 烘干机数，每 30 分钟自动刷新
  • 洗衣房小组件与长按应用图标「洗衣房」快捷方式点击直达上次浏览的楼栋设备页
  • 上次浏览的楼栋自动记忆，再次进入直接打开；无楼栋门店（如含辉苑）直接进入全部设备
  • 修复部分教务系统（超星等）登录页在桌面模式下只显示背景、登录框打不开的问题：该站登录页依赖 body 撑高布局，此前注入的固定宽度 viewport 会把它算成 0 高度而被整体裁掉
  • 修复内嵌浏览器请求头透传：不再额外剥离 Accept-Encoding 等头，避免服务端按非浏览器客户端降级返回
  • 内嵌浏览器补齐桌面模式文字自适应；切回手机模式复用系统原始 UA
  • 通用适配器新增顶栏网址输入：没有默认入口时直接进入输入态，标题栏显示教务页标题，随时可改教务网址
  • 启动速度优化：偏好首读、玻璃背景图解码、首页考试数据读取移出主线程，缓解冷启动卡顿
