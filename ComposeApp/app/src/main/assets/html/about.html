不挂科课表

版本 - · 选学校 · 登教务 · 一键导入课表

主要功能

教务网页导入选学校登录教务，一键导入课程、周次、地点与教师
宿舍开门登录一次后本机蓝牙开门；支持长按图标「快速开锁」，可选指纹/面容验证
多课表与周视图多套课表并存随时切换，左右滑动换周、今日高亮
今日页正在上课 / 下一节课 / 今日时间轴
桌面小组件2×2 / 2×3 / 2×4 三种规格，可分别绑定课表
上课提醒课前 5/10/15/20 分钟本地通知，准点触发
系统日历同步课程直接写入系统日历，可一键清空
课表对比与调课截图识别占用找共同空闲；长按拖拽跨天跨节次调课
个性化深色模式、动态取色、磨砂玻璃、自定义背景与作息

更新记录
