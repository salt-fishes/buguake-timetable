# 不挂科课表

从"简课表"进化而来的 Android 课表应用：**教务网页一键导入**为核心能力，
适配学校教务系统的课表导入由社区适配脚本生态驱动，无需手写解析规则。

> 🚧 **项目状态：开发中**（v0.x）。本仓库刚从简课表代码库派生，
> 联网导入能力正在开发，功能列表以下方"路线图"为准。

## 定位

- 🌐 **教务网页导入**：选择学校 → 内嵌浏览器登录教务 → 一键导入课表（课程/周次/节次/地点/教师）
- 🗂 **多课表管理**、📅 **周视图**、⏰ **今日页**、📱 **桌面小组件**、🔔 **上课提醒**、
  🗓 **系统日历同步**（继承自简课表的成熟能力）
- 📊 **课表对比**：与其他课表应用的截图对比空教室/空时段（继承自简课表）

## 与简课表的关系

- 继承：数据层、课表 UI、小组件、提醒、日历同步、课表对比
- 舍弃：PDF/Excel/截图的离线 OCR 导入与解析规则包系统（简课表将继续维护离线导入能力）
- 新增：基于拾光课程表开源生态的教务网页导入（桥协议与适配脚本见
  [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)）

## 隐私

教务账号密码只在内嵌浏览器会话内使用，App 不读取、不保存、不上传；
课表数据全部存于设备本地。详见 [PRIVACY_POLICY.md](PRIVACY_POLICY.md)。
