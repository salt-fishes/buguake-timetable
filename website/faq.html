常见问题 F.A.Q.

没能解答你的问题？欢迎到 GitHub Issues 反馈，附上教务网址、学校名称与截图会处理得更快。

1我们学校不在列表里怎么办？
选择学校页找不到本校时，可以使用通用适配器：在顶栏直接输入本校教务系统网址即可进入登录与导入流程，正方、超星、青果、URP 等主流教务均支持。也可以到 本仓库 Issue 反馈学校名称与教务网址。
2导入适配突然失效了，为什么？
教务导入建立在开源适配生态（拾光课程表 + 社区学校索引）之上，学校教务系统改版可能导致脚本失效。修复方式：到 拾光适配仓库 提 Issue/PR，或在本仓库附上教务网址、学校名称、失败截图或日志（内嵌浏览器页面里可长按复制报错），合并后 App 重新同步索引即可生效，无需更新客户端。
3和「简课表」是什么关系？
不挂科课表派生自同一作者的前作「简课表」。简课表主打 PDF/Excel 本地 OCR 导入（完全离线）；不挂科课表进化为教务网页一键导入，并加入宿舍蓝牙开门、考试安排、洗衣房等校园能力。两者是相互独立的应用，数据不互通。
4我的教务账号密码安全吗？
教务账号与密码只在内嵌浏览器会话内使用，App 不读取、不保存、不上传，导入完成后可一键清除会话。云莓账号密码与门锁密钥只存本机，经 Android Keystore 的 AES-256/GCM 加密，登录请求由手机直连云莓服务器、App 不中转。详见 隐私政策。
5真的不收集数据吗？
不收集、不上传任何个人身份信息：课表本地存储、无广告、无统计埋点、无第三方 SDK 上报；不参与系统云备份与换机迁移；卸载 App 即删除全部本地数据。联网行为仅限下载适配脚本、加载你主动选择的教务网站、开门首次登录同步、考试读取与洗衣房只读查询，逐项列于 隐私政策。
6考试安排支持哪些学校？
当前适配正方教务：在应用内登录教务系统后读取考试时间、考场与座位，可写入系统日历「不挂科考试」或导出 .ics，结果加密缓存在本机、可随时清空。其他教务体系的考试读取暂未覆盖，欢迎提 Issue 需求。
7日常开门需要联网吗？
不需要。宿舍开门离线优先：登录一次后门锁密钥加密保存在本机，日常开门完全通过本机蓝牙完成，不再联网、不再重复登录。可选「开门前验证指纹/面容」，支持「长按应用图标 → 快速开锁」。注意该接口基于第三方逆向实现，可能随官方更新失效。
8洗衣房要登录吗？会扣费吗？
查询无需登录、不上传任何数据：直连顺水平台只读查询门店与洗衣机/烘干机状态（哪台空着、剩余时间倒计时）。下单、支付、启动设备全部跳转官方小程序完成，App 不碰支付与设备控制；定位仅在你点「附近门店」时使用一次，拒绝授权可改用门店名搜索。
9升级会丢数据吗？支持什么系统？
Releases 下载的 APK 覆盖安装不丢数据。支持 Android 8.0 及以上（arm64-v8a）；背景模糊与动态取色需 Android 12+（低版本自动降级），指纹验证需 Android 9+。当前最新版本见 下载区。
10失效了要负责吗？和官方有关系吗？
教务导入与宿舍开门基于第三方逆向接口，可能随学校或官方系统更新而失效；洗衣房基于顺水平台逆向接口，覆盖以官方为准。请仅将其用于个人课表管理与开门等合法用途，使用后果由使用者自行承担。本项目与任何教务系统厂商、云莓智能官方、顺水平台官方均无关联。完整表述见 首页免责声明。
