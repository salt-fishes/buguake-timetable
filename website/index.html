HIGHLIGHTS · 三大特色

不只是课表，是校园生活工具箱

🌐

教务网页一键导入

选择学校（200+ 覆盖）→ 内嵌浏览器登录教务 → 课程/周次/节次/地点一键导入。正方、超星、青果、URP 通用适配器，输入本校网址即可。

🚪

宿舍蓝牙开门

登录一次，门锁密钥加密存本机；日常开门不再联网、不再重复登录。支持指纹/面容验证、长按图标快速开锁。

🧺

洗衣房空闲查询

哪台洗衣机空着、还剩多久实时倒计时，空闲的排前面；一键跳官方小程序开洗。无需登录、不上传数据。

MORE · 还有这些

📝

考试安排

应用内登录正方教务，读取考试时间/考场/座位，写入日历或导出 .ics，本机加密缓存。

📊

周视图 / 今日页

滑动切周、当前时间线、自定义时间段课次自动落格。

✏️

拖拽调课

长按拖拽换位，可选「以后每周」或「仅本周」。

📱

桌面小组件

课程 2×2 / 3×2 / 4×2（今明双栏）＋ 洗衣房 2×1 空闲速览。

🔔

上课提醒

课前 5/10/15/20 分钟本地通知，准点触发、重启自动恢复。

🗓

日历同步

课程写入「不挂科课表」、考试写入「不挂科考试」，可分别清空。

🆚

课表对比

截图识别占用，找共同空闲（实验性）。

🎨

个性化

深色模式、动态取色、磨砂玻璃、自定义背景。

🧿

你的数据，只留在你的手机上

课表全部本地存储；教务账号密码只在内嵌浏览器会话内使用，云莓凭据与门锁密钥经 Android Keystore AES-256/GCM 加密存本机；洗衣房查询无需登录。无广告、无统计埋点，卸载即删除全部本地数据。

🙌 为你的学校适配出一份力

教务导入能力完全建立在开源适配生态上——适配器是 JavaScript 脚本 + 学校索引，新增一所学校不用改客户端代码，非常适合作为第一次贡献。

去适配仓库提 PR ↗ 反馈问题 ↗
① 新增/修复学校适配 → 拾光适配仓库提 Issue/PR
② 只反馈问题 → 本仓库 Issue，附网址与截图
③ 客户端改进 → 代码/界面/文案 PR 欢迎

⚠️ 免责声明：教务导入与宿舍开门基于第三方逆向接口，可能随官方系统更新失效；洗衣房基于顺水平台。请仅用于个人课表管理与开门等合法用途。本项目与任何教务厂商、云莓智能、顺水平台官方均无关联。
